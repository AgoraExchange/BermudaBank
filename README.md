# Bermuda Bank — Private Wealth Management

A luxury private banking PWA (Progressive Web App) built for iPhone.

## Add to iPhone Home Screen

1. Host this repo on **GitHub Pages** (free):
   - Go to your repo → Settings → Pages → Source: `main` branch → `/root`
   - Your URL will be: `https://yourusername.github.io/bermuda-bank`

2. On your iPhone, open Safari and visit the URL.

3. Tap the **Share button** (box with arrow) → **Add to Home Screen**

4. Name it **Bermuda Bank** and tap Add.

The app will appear on your home screen with a gold "B" icon and launch in full-screen mode — no browser chrome, no address bar. Looks and feels 100% native.

## Features

- **Dashboard** — Net worth display, cash flow chart, recent transactions
- **Cards** — Prestige Black, Platinum & Business card stack with stats
- **Transfer** — Send money with numpad, recent recipients
- **Portfolio** — Investment holdings, YTD performance
- **Profile** — Account settings, preferences, private banker access

## Tech

Plain HTML/CSS/JS — no frameworks, no dependencies. Pure front-end.
Fully offline-capable after first load via Service Worker.
